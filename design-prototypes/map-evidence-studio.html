Transparency by design

A map is not evidence on its own.

Beautiful geography must never make weak or fabricated property information look more certain.

What this prototype can demonstrate

It demonstrates two genuinely different design directions, a connected evidence-list and diagram selection state, responsive layout, shortlist comparison, and appropriately visible unsupported-case language.

What it does not demonstrate

It does not access the Python service, read saved investigations, supply true geospatial positions, call a geocoder, display licensed map tiles, authenticate users, save notes to the database, or derive property prices. All labels, building shapes, roads and numbers are invented design fixtures.

How the real map must eventually work

First create source-backed and versioned parcel geometry tied to the exact saved investigation and frozen comparable evidence. Distinguish parcel centroid from building location, validate source permissions and coordinate accuracy, and select a tile supplier independently of the renderer. Only then connect MapLibre, Leaflet or another justified library. The existing six fixture parcels currently share the same test coordinates.
