## PI5 offline identity boundary
Pinned issuer/client/RS256 keys; authorization code with S256 PKCE, state tied to a random browser binding, single-use callback, nonce, issuer/audience/expiry/iat and owner mapping. Uses PyJWT library with locally generated RSA test keys, no network or provider. In-memory bounded hashed opaque sessions, CSRF/origin for mutations, Secure/HttpOnly/SameSite cookies, idle/absolute expiry and logout. No production route or browser cookie transport, persistent session store, key rotation/discovery, actual provider or production deployment. Existing Basic loopback runtime unchanged. Reference: https://www.rfc-editor.org/rfc/rfc9700.html and https://pyjwt.readthedocs.io/en/latest/api.html .
