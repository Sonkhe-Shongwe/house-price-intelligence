# Synthetic Geographic Evidence Integration V1
**Owner-authorised implementation, 24 November 2026.** Scope: fictional, loopback-only, opt-in; real geography and release remain blocked.

## Requirements, architecture and risks
React integration PR #8 accepted and merged into development at c3582b441e2959c262f4d52bb15e7e5286ce6599 after four exact-head CI workflows passed (176 Python, 16 legacy browser, 28 React acceptance). No main merge or deployment. Preserve canonical investigation/shortlist persistence, matching policy and original schema/fixture checksums. The original six overlapping coordinates participate in matching; changing them could change historical results. Instead, the independent immutable virtual display source synthetic-display-geography-v1 is keyed to the existing trusted synthetic build and parcel IDs, with a deterministic SHA-256 of its versioned contents. Its points are intentionally not physical locations or scale evidence, not real parcel centroids or historical as-of proof. Existing saved results are unchanged; the read-only map is supplementary and generated from that pinned display source, not an assertion that these positions were saved in the original investigation. A future source revision must receive a new version and an explicit compatibility decision; never modify v1 silently.

## Implementation and contract
Use the same WSGI launcher with --fixture-only --frontend react --synthetic-map. GET /v1/investigations/{uuid}/map is read-only. It reopens the frozen result, checks the full original trusted source signature, build and original geography snapshot role, persisted subject and selected comparable identities/ranks. Response synthetic-map-v1 includes build/UUID, source kind, virtual display geometry kind, versioned position source ID/hash, real_geography_verified=false and distance_supported=false; GeoJSON [longitude,latitude] points only when the result supports evidence and all positions exist. Insufficient, disabled or missing geometry yields empty features. Corrupted source returns evidence_unavailable. No requester coordinates or external services. Default legacy and non-map React modes unchanged. The React adapter checks identity, rank, counts, version, bounds, uniqueness and flags before lazy-loading MapLibre with same-origin worker. Marker buttons and sale cards share selection. Map failure leaves the original evidence usable. CSP adds only worker-src 'self' for opt-in React assets; no external resource origins. No basemap or distances. No SQLite migration.
