## Design and technology guardrails

- Atlas Atelier is the working candidate, not approved branding. Preserve existing design tokens and deliberate editorial/analytical hierarchy; use one coherent icon style, not emoji/Unicode as primary navigation icons. Keep symbols meaningful, sparse and consistent.
- Evaluate Lucide, Base UI and Motion selectively, not a mandatory shopping list. Storybook, D3, Tailwind, chart libraries and new font assets are optional only if measured utility justifies them. Review actual versions, peer compatibility, licence and attribution, pinned lockfile, installed/compiled size, vulnerability results, CSP, same-origin assets, no external requests, fallback and browser tests before adoption. No paid services.
- Preserve source seals, price-free matching, earlier-only evidence, exact cents, owner isolation, CSRF, session boundary, redaction, no geometry when unavailable and no valuation. No new API disclosure or persistence capabilities without separate contract review. Private and synthetic service adapters must remain distinct.
- Apply the [eight-step lifecycle](LEAN_ENGINEERING_DIRECTIVE.md), permanent development branch, stable main, exact-head CI and [cloud-first workflow](CLOUD_FIRST_WORKFLOW.md). Do not repeatedly ask for routine approval. Stop at genuine owner, rights, cost, credential, access, destructive or release boundaries.
- Accessibility and performance goals are targets, not current results. Proposed aesthetic rubric in art-direction research remains subjective and unapproved. Existing accepted P0–P8 weights and gates are unchanged.
