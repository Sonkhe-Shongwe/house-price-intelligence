# House Price Intelligence: execution roadmap

[Checkpoint](CHECKPOINT.md) owns current task, blockers and verified implementation; [decisions](DECISIONS.md) owns approvals. Read those sources, not duplicated progress figures.

The MVP is a buyer-facing property investigation and P6 two-to-three-property shortlist, not a validated valuation model. Audit research phases 0-2 are not delivery P0-P8. Full phase acceptance requires the original applicable gates and owner authority; synthetic CI, a code commit or an engineering estimate does not close a gate.
