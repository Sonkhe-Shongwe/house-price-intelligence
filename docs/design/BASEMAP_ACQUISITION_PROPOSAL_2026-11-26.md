## Owner approval envelope

| Control | Proposed hard limit |
| --- | --- |
| Acquisitions | One controlled regional archive extraction attempt, no automatic retries or substitute sources |
| Archive source | Only named v4 mirror object, preflight identity pinned; abort if metadata inconsistent |
| Requested bounding box | -87.76,42.00,-87.64,42.09 |
| Archive zoom | 0–15; camera 10–15; no expanded coverage |
| Archive remote response bodies | At most 64 MiB (67,108,864 bytes) in aggregate, counting metadata/header/ranges and failed partial reads |
| Result archive | At most 50 MiB (52,428,800 bytes) |
| Archive range requests | At most 1024; each at most 8 MiB, sequential or concurrency explicitly reserved under aggregate byte cap |
| Tool, glyph and sprite acquisition | At most 32 MiB combined response bodies; only pinned reviewed package/release assets with notices, no complete unrelated asset collection |
| Total bounded acquisition payload | At most 96 MiB, inclusive of above; ordinary pre-existing locked application CI dependencies separate from acquisition |
| Acquisition duration | At most 10 minutes; terminate on limit, no auto retry |
| Storage | One disposable temp directory, <=128 MiB total acquisition files, no Git, Drive, persistent database or uploaded archive |
| Retention | Dispose acquisition files at end of job even on error; retain only aggregate counts, sizes, checksums, version/notice manifest, sanitized diagnostics and permitted contextual screenshots, seven-day CI artifact retention |
| Cost | R0 additional paid commitments; no account/token/bucket/worker/billing, no owner mobile bandwidth requirement |

These ceilings are engineering choices, not measured file size or predicted transfer. A cap breach is a truthful blocked result, not authority to widen scope. Do not run the raw CLI against public remote source unguarded: --bbox and --maxzoom limit coverage, not transfer. Implement and test a local acquisition gateway or equivalent strict transport guard **before** live invocation: allowlist exact HTTPS object, reject redirects and non-206 responses before body read, validate Content-Range and pinned identity, reject missing/oversized lengths, reserve aggregate response bytes before request/stream, count bytes actually read including partial failure, cancel when budget exhausted. HEAD is metadata only, no full-object GET. Limit request count and duration; no other public tile traffic. Tool/asset fetches have separate enforced cap, integrity and origin allowlist. No unsafe fallback to whole planet or unmetered public tile fetching.
