# Atlas Atelier / Intelligence Terminal visual study

26 November 2026. Standalone review candidate, not application integration or approved design. [Open the HTML source](../../design-prototypes/hpi-atlas-terminal-study.html) in a browser after downloading. Same fictional buyer task, two switchable themes with distinct map/evidence composition. Sign-in simulation, empty and returning workspace, exact fictional address search, supported and insufficient dossier, conditional schematic map with linked selection, saved records, two-property comparison and notes, methodology, mobile evidence/map views. No backend, real coordinates, network calls, authentication, persistent storage or valuation. Fixed demo data includes illustrative area/date details, not an assertion of the exact recorded Neon fixtures. The schematic is deliberately not to scale and defaults off to reflect the private contract. Session state is cleared on exit, resets on reload. Review-only, no production frontend or dependency changes. Visual verification remains pending; no new acceptance or score. See [convergence audit](FRONTEND_CONVERGENCE_AUDIT_2026-11-26.md) and [art direction](ART_DIRECTION_AND_DESIGN_CRAFT_RESEARCH_2026-11-26.md).
